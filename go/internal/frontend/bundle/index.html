Sonarr

This binary was built without an embedded frontend bundle. The placeholder you're reading lives in go/internal/frontend/bundle/index.html; the production build replaces this whole directory.

For developers: run npm run build in the repo root, then cp -r frontend/build/* go/internal/frontend/bundle/, then go build ./cmd/sonarr to produce a single-binary distribution with the React UI embedded. Alternatively, pass --frontenddir=./frontend/build at runtime to mount the build output without an embed step.

The REST API at /api/v3/* and the SignalR hub at /signalr/messages are live regardless — they don't depend on the frontend bundle.
